# 🦖 Dino Run Game

A browser-based endless runner game inspired by the Chrome Dinosaur game.

## 🎮 Features
- Jump and duck mechanics
- Cactus and bird obstacles
- Normal and Hard difficulty modes
- Score and high-score tracking
- Restart using keyboard or button
- Responsive full-width canvas
- Desert-style background

## 🛠️ Technologies Used
- HTML5 (Semantic Structure)
- CSS3 (Responsive Design)
- JavaScript (Game Logic & Interactivity)
- HTML Canvas API
